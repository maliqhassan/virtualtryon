# design/

Design references and source files — not consumed by app builds (compare to
`frontend/assets/`, which *is* bundled into the app).

- `design-system/` — design tokens (color, type, spacing) once a visual
  identity is defined. Empty for now; fabricating a color palette without
  actual design input would just be guessing.
- `figma/` — exported Figma assets (icons, illustrations) as they're
  finalized.
- `wireframes/` — low-fidelity flow/screen wireframes preceding
  implementation.
